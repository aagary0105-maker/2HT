# 二手買賣利潤記錄 (Secondhand Profit Tracker)

🛍️ A lightweight React app to track and manage secondhand item sales and profits.

## ✨ Features

- **📊 Dashboard Summary**: Real-time overview of total buy cost, target price, actual revenue, and net profit
- **🔍 Search & Filter**: Search by item name or notes, filter by status (All/Holding/Sold)
- **📈 Sorting**: Sort by date (newest/oldest) or name (A-Z/Z-A)
- **📋 Item Management**: Full CRUD operations for tracking secondhand items
- **💾 Auto-Save**: All data automatically saved to browser localStorage
- **📱 Responsive Design**: Works seamlessly on desktop, tablet, and mobile
- **🌙 Dark Theme**: Easy on the eyes with a modern dark UI

## 🚀 Quick Start

### Prerequisites
- Node.js 14+ and npm

### Installation

```bash
# Clone the repository
git clone https://github.com/aagary0105-maker/2HT.git
cd 2HT

# Install dependencies
npm install

# Start the development server
npm start
```

The app will open at `http://localhost:3000`

### Build for Production

```bash
npm run build
```

This creates an optimized production build in the `build/` directory.

## 🎯 How to Use

1. **Add Item**: Click "＋ 新增商品" to add a new secondhand item
2. **Fill Details**: Enter item name, buy price, target price, and notes
3. **Mark Sold**: When item is sold, enter the actual sell price
4. **Track Profit**: Automatically calculates profit/loss for each item
5. **Search & Filter**: Use search box and tabs to find specific items
6. **Edit/Delete**: Modify or remove records as needed

## 💾 Data Storage

- All data is stored in your browser's localStorage
- Data persists across browser sessions
- No cloud storage or external API required
- Data is local to your device only

## 🛠️ Tech Stack

- **React 18**: UI library
- **React Scripts 5**: Build configuration
- **CSS3**: Styling with responsive design
- **localStorage API**: Data persistence
